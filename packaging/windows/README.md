# 1n9 บน Windows (.exe)

ใช้โค้ด node ชุดเดียวกับ Docker ทุกบรรทัด — ต่างแค่วิธีติดตั้ง

## สร้างไฟล์

```powershell
powershell -File packaging\windows\build.ps1
# ผลลัพธ์: packaging\windows\dist\1n9\1n9.exe (โฟลเดอร์ ~125 MB รวม Qdrant)
```

ต้องมี Python 3.13 และ Node.js 20 (ใช้ build หน้าเว็บถ้ายังไม่มี `frontend\out`)

## พฤติกรรม

- เปิดแล้วรัน node ที่ `http://127.0.0.1:8080` (ถ้าพอร์ตไม่ว่างลอง 8081…) แล้วเปิดเบราว์เซอร์ไปหน้าหลังบ้าน
  ซึ่งพาไปหน้าตั้งค่าครั้งแรกเองถ้ายังไม่ได้ตั้ง
- ข้อมูลทั้งหมดอยู่ที่ `%LOCALAPPDATA%\1n9\data` (ลบโปรแกรมข้อมูลไม่หาย) · เปลี่ยนด้วย `NODE_DATA_DIR`
- เปิดซ้ำตอนที่รันอยู่แล้ว = แค่เปิดหน้าเว็บให้ ไม่เปิดตัวที่สอง
- `--no-browser` ไม่เปิดเบราว์เซอร์ (ไว้ทดสอบ)
- ค่าอื่น ๆ ตั้งผ่านตัวแปรสภาพแวดล้อมเหมือน `.env` ของ Docker (`NODE_PASSWORD`, `CENTRAL_URL`, …)

## Qdrant ในตัว

- `build.ps1` โหลด Qdrant สำเร็จรูป (เวอร์ชันเดียวกับ docker-compose) แล้วตรวจ SHA256 ก่อนแพ็กทุกครั้ง
  อัปเดตเวอร์ชัน: เทียบค่าแฮชกับหน้า release ของ Qdrant ก่อนแก้ใน `build.ps1`
- เปิดเป็นโปรเซสลูกที่ `127.0.0.1:16333` พร้อม **API key ที่สุ่มครั้งแรก** (`%LOCALAPPDATA%\1n9\qdrant_api_key`)
  จำเป็น เพราะ Qdrant ตอบ CORS แบบเปิดกว้าง ถ้าไม่มี key เว็บไซต์ใดในเบราว์เซอร์ลูกค้าอ่านฐานข้อมูลผ่าน localhost ได้
- ผูกกับ Job object ของ Windows: 1n9.exe ถูกฆ่ากะทันหัน Qdrant ตายตาม ไม่ค้างล็อกข้อมูล
- node ใช้ชนิด `local` (ผ่านท่อเชื่อมไป central) เหมือน docker-compose
- **ข้อจำกัดเส้นทางไฟล์:** Windows จำกัด 260 ตัวอักษร ส่วน Qdrant สร้างไฟล์ลึกราว 120 ตัวใต้โฟลเดอร์ข้อมูล
  โฟลเดอร์ข้อมูลปกติ (~65 ตัว) ปลอดภัย แต่ถ้ายาวเกิน 110 ตัว โปรแกรมจะไม่เปิด Qdrant และเขียนสาเหตุลง stderr
  แก้ด้วย `NODE_DATA_DIR` เป็นเส้นทางสั้น ๆ (ตัวติดตั้งต้องเลือกที่เก็บให้สั้นเอง)

## ตัวติดตั้ง (`1n9-Setup.exe`)

```powershell
powershell -File packaging\windows\build.ps1 -Version 1.0.0   # สร้างทั้งโฟลเดอร์และ 1n9-Setup.exe (ต้องมี Inno Setup)
```

- ติดตั้งแบบรายผู้ใช้ลง `%LOCALAPPDATA%\Programs\1n9` — **ไม่ต้องสิทธิ์ผู้ดูแล ไม่ขึ้น UAC** · กด Next → Finish
- ตัวเลือก: ไอคอนบนเดสก์ท็อป · เปิดเองตอนเข้า Windows (เปิดเงียบ ๆ ที่ไอคอนมุมจอ ไม่เด้งเบราว์เซอร์)
- โปรแกรมไม่มีหน้าต่างดำ: ไอคอนที่มุมจอ (เมนู "เปิดหน้าเว็บ" / "ปิดโปรแกรม") · log อยู่ที่ `%LOCALAPPDATA%\1n9\1n9.log`
- อัปเดต = รันตัวติดตั้งเวอร์ชันใหม่ทับ (ปิดโปรแกรมที่รันอยู่ให้เอง) ข้อมูลไม่หาย
- ถอนการติดตั้งลบแต่ตัวโปรแกรม **เก็บข้อมูลลูกค้าไว้** ที่ `%LOCALAPPDATA%\1n9` และบอกที่อยู่ให้
- ยังไม่เซ็นรับรอง (code signing): Windows จะขึ้นเตือน SmartScreen ครั้งแรก → "More info" → "Run anyway"
- ตัวติดตั้งเป็นภาษาอังกฤษ (Inno Setup ไม่มีภาษาไทยในชุดทางการ)
